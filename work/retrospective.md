# Capstone Retrospective (FL-10)
**Author:** Pervaiz Ahmed | **Track:** FlyRank Machine Learning Internship

### Reflecting Back: Week 1 vs. Graduation
When I started this track, machine learning felt like isolated algorithmic optimization in Jupyter notebooks. Working with 79M production telemetry rows shifted my paradigm toward end-to-end data engineering, feature leakage prevention, and public reproducibility.

### Three Transferable Lessons
1. **Feature Integrity over Model Complexity:** Strict train-test temporal splits prevent target leakage.
2. **Data Hygiene & Public Safety:** PII and proprietary query parameters must be systematically sanitized.
3. **Technical Communication:** Communicating model trade-offs via live papers and demo videos ensures stakeholder alignment.

### Next Steps
Building real-time streaming inference using Apache Kafka to capture live search engine algorithm updates.
